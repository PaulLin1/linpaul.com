A interval timer app based off the TITLE Classic XL Digital Gym Timer and a Bauhaus/De Stijl design by campaign ltd.. 

## Background

The functionality of this timer is really simple. The timer is a loops alternating between 'on' time and 'off' time, allowing you to train with set rest times. To edit settings, you click a mode and increase or decrease. The mode system reminded me of my old Casio watch that had allowed you to edit the time, alarms and stopwatch on a simple interface.

## Process

A majority of the time building was spent on the UI. At first, I wanted to replicate the feel of the TITLE clock. I was drawn to its brutalist vintage look that was really muted. The item looked tough the way concrete looked tough, not how stainless steel or metal did.

With the TITLE timer interface, I learned how to use a reference as reference. The interface does not translate well to a phone because it is horizontal, So i moved the clock to the top third of the screen while having the controls at the bottom. I learned that translation means not only understanding the reference, but the form that you translating to.

After using this UI for a while, I realized that I wanted a more modern feel. Although I still like the physical timer, a digital recreation of it felt tacky. So I decided to build a new interface.

Without a clear reference, I decided to go to the campaign ltd. Instagram page, one of my favorite places for inspiration. There posts are simple, but pop with their color, font, and form choices. A particular post stood out to me and I decided to use it as a reference. It had campaign ltd.'s distinct color palette as well as a cross motif.

The earlier lesson I learned of using a reference as a reference helped me a lot as I tried to transfer the cross motif to my app. At first, I just had the cross in the background but it felt really forced. But then I realized how I can use the cross as a component that helps show selection. Not only did it look good, but it also had a clear purpose. Despite first going to Instagram for color inspiration, it also helped me with design choices.

## Outcome

Wondering about digital ui and how it differs from physical objects. comparing the 2. not having form or qualities of materials.

This was a fun weekend project that also helped me learn a bit of React Native. I currently use the app everyday when I hit the boxing bag. I usually have it set for 3 minutes on and 1 minute rest for 5 rounds.

I do not plan on releasing this to the App Store as the background timer is a bit crude. But if you want to use it, the code can be found on my GitHub.
